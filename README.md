# Shutdown Helper

A lightweight Rust-based utility to remotely shut down a Windows machine via a secure HTTP REST endpoint. Designed primarily for integration with smart home systems like Home Assistant.

## Features

- **Windows Service Support**: Runs silently in the background as a native Windows Service.
- **Secure Authentication**: Requires a configurable `X-Auth-Token` header for all requests.
- **Safe by Default**: Binds to `127.0.0.1` by default to prevent unauthorized network access unless explicitly configured.
- **Audit Logging**: Maintains a rolling log of all shutdown attempts (authorized and unauthorized).
- **Optimized Performance**: Small binary size with LTO and native CPU optimizations.

## Installation

1. **Build**:
   ```powershell
   ./setup.ps1
   ```
   *Note: This requires Administrator privileges and will install the helper to `C:\Program Files\ShutdownHelper`.*

2. **Configure**:
   Edit `C:\Program Files\ShutdownHelper\config.toml` to set your desired port and `auth_token`.

3. **Restart Service**:
   ```powershell
   Restart-Service ShutdownHelper
   ```

## Usage

Send a `POST` request to the `/shutdown` endpoint:

```bash
curl -X POST http://localhost:8080/shutdown \
     -H "X-Auth-Token: your-secret-token"
```

## Configuration Options

- `port`: The port the server listens on (default: `8080`).
- `bind_address`: The IP address to bind to (default: `127.0.0.1`).
- `auth_token`: The token required in the `X-Auth-Token` header.
- `log_dir`: Directory where audit logs are stored.

## Home Assistant Integration

Add the following to your `configuration.yaml` to create a button for shutting down your PC:

```yaml
rest_command:
  shutdown_pc:
    url: "http://<YOUR_PC_IP>:8080/shutdown"
    method: post
    headers:
      X-Auth-Token: "your-secret-token"
```

You can then trigger this via a button card or automation:

```yaml
type: button
name: Shutdown PC
icon: mdi:power
tap_action:
  action: call-service
  service: rest_command.shutdown_pc
  confirm:
    text: Are you sure you want to shut down the PC?
```
